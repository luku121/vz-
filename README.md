# Calculadora web

Proyecto sencillo de calculadora en HTML, CSS y JavaScript inspirado en el ejemplo compartido.

## Funcionalidades

- Operaciones básicas: suma, resta, multiplicación y división.
- Botones de limpieza (`C`), cambio de signo (`±`) y porcentaje (`%`).
- Soporte para números decimales.

## Ejecutar

No requiere instalación. Abre `index.html` en tu navegador.
